Overview

Slices 1 and 2 made the Floor move only when the coordinator moved: a parcel slides when an item changes state, and outcomes (merged, shipped, failed) pop a label. Between transitions, the edge already streams tail and ci messages for up to six watched items (BOB-94), but only the desk text used them, so the Floor sat still while agents worked for minutes.

This slice turns that same websocket stream into motion. A pure lens in @bob/arcade diffs successive tail frames and CI messages into beats. Web and native draw the same beats. The rule from BOB-91 still holds: nothing moves that isn't a real event. Live activity gets ambient motion, and outcomes get labels, confetti and haptics.

Data flow

SdlcEdge DO→ ws → tail · ci (watched ≤ 6)→ tailBeats · ciBeats→ BeatLog (dedupe)→ effectFor→ sparks · typing · meters · stamps · confetti · haptics

The coordinator path (sdlcBeats) is unchanged. Both paths share one beat log per screen, so the ticker, effects and haptics see one ordered, deduplicated stream.

Goals & non-goals

Goals

  • Beats from tail frames: activity, plus named commands (test, typecheck, lint, build, install, commit, push) with exit codes
  • Beats from CI: per-phase status changes and one ci.green per run
  • A motion grammar for them, shared by web and native
  • Scope chips per project and repo; floor height and parcel density scale with load
  • Custom station graphics that move only while their station holds items

Non-goals

  • Edge or protocol changes: the stream already exists
  • Watching more than six items: desks still pick the watch set
  • Sound, XP or replay (phase 5)
  • Native dependencies (no react-native-svg): the change ships over the air

other command exit ≠ 0spark OOPSnoneWhimsy, but true
ci.phase → runningspark ▶ PHASEnone
ci.phase → passedpulse ✓ PHASEnone
ci.phase → failedstamp ✗ PHASE, web spectacle failure bursterrorReal failure
ci.greenconfetti + GREEN, web spectacle burstsuccessOutcome
A first frame, a new attempt or a new CI sha is a baseline, never an event, just as a first snapshot or a new epoch is for sdlcBeats. Opening the screen celebrates nothing. Beat ids are stable, so a replayed frame is dropped by the log.

Risks & mitigations

RiskLevelMitigation
Noise: tail frames arrive every ~2 s per watched itemMediumActivity never shows text, never gets a ticker line and never triggers a haptic. The effect cap is 24 on native and 32 on web. Effects for items scoped off the floor are dropped.
Misclassified commands (a commit message mentioning "lint")LowGit rules match first; a miss only changes a label, never state
Window shifts with no overlap flood beatsLowCapped to the newest 8 lines
Motion for people who asked for lessLowWeb: the cockpit's minimal level stops all animation. Native: reduced motion removes travel, sparks and glyph motion.
