Outcome

Exact native console

Recreate the stale branch’s header, health badge, three status cards, connector cards, automation controls, recent sessions, notices, errors, and stock-dashboard link.

Full proxy surface

Restore authenticated /hermes/* dashboard proxying and /api/hermes/* management API proxying in the Cloudflare Worker.

Current trust boundary

Keep Hermes bound to loopback behind nginx. Authenticate at Bob, require an explicit operator allowlist, carry a dedicated HERMES_PROXY_ORIGIN_TOKEN server-side, and never persist connector secrets in Bob.

What already exists

  • Hermes dashboard and gateway are live behind claude.gmac.io/hermes/ and nginx auth_request.
  • Bob’s Worker already exposes /api/internal/hermes-origin-auth, validates Bob sessions, and accepts a timing-safe HERMES_ORIGIN_TOKEN for narrow service calls.
  • The current notification integration already bootstraps Hermes’ rotating dashboard token on the server.
  • The stale branch contains the approved console JSX, typed response shapes, client actions, proxy request builders, and unit-test intent.

The stock dashboard necessarily receives Hermes’ own short-lived dashboard token in its upstream HTML because that SPA needs it. The Bob-native console does not: its management calls terminate at the Worker, which bootstraps and attaches the rotating token server-side.

Implementation tasks

Define and test the proxy boundary

Add focused tests first for path matching, safe URL construction, header stripping/injection, login redirects, upstream response hygiene, token extraction, operator authorization, same-origin mutations, allowed native actions, and malformed connector input.

Files: apps/bob/src/lib/hermes-proxy.ts, its tests, apps/bob/worker/index.ts.

Restore Worker routing

Authenticate both proxy surfaces with Bob’s actual auth runtime, require the configured operator allowlist, validate the configured HTTPS origin and browser Origin on mutations, add the proxy bearer only in Worker memory, strip Bob credentials before Hermes, bootstrap the rotating token for native API calls, and preserve safe response headers/body streaming.

Add the typed console model and client

Keep console-specific types and transformations app-local. Fetch status, platforms, jobs, sessions, and providers in parallel behind one overview call. Expose only explicit mutation methods.

Port the stale UI exactly

Use the current shared UI primitives and layout, preserving text, hierarchy, controls, 30-second refresh, mutation notices, and responsive card/list behavior.

Integrate navigation and operations contract

Add Hermes as a utility destination without changing Bob’s two-mode shell. Extend the nginx contract only if live proxy proof reveals a missing header or route.

Verify, review, ship, and deploy

Run focused tests, app typecheck, production build, full serial tests, authenticated browser QA, diff review, PR checks, merge, Worker deployment, and live route verification.

Test flow and failure modes

request -> route match -> Bob auth -> operator/origin gate -> token bootstrap -> upstream fetch -> sanitized response
   |          |             |               |                        |                 |
  404      no bleed       401/302         403/405                    502               502
Codepath Production failure Coverage / handling / user signal
Bob authentication Expired or missing session Tested; HTML redirects to login, API returns 401.
Operator and browser-origin authorization Valid Bob user is not an operator, or a mutation is cross-origin Tested; fail closed with 403 before any Hermes fetch.
Origin configuration Malformed or non-HTTPS origin Tested; fail closed with 502, never issue an arbitrary fetch.
Token bootstrap Hermes HTML changes or upstream is down Tested; 502 with a clear console error and retry.
Overview fan-out One upstream subrequest fails Tested; entire snapshot rejects so stale mixed state is not presented.
Connector mutation Malformed token or Hermes rejects it Tested; 400/structured upstream message shown, secret not logged.
Cron mutation Job disappears between poll and click Handled as upstream error; visible notice; query revalidates after success.
Stock dashboard proxy Redirect/header points at origin host Test response rewriting/stripping; browser remains on Bob origin.

Critical silent gaps: none after the tests above land.

Performance review

  • One browser poll fans out to five independent Hermes reads in parallel.
  • TanStack Query uses 15-second freshness and 30-second polling, matching the approved stale UI.
  • Mutations invalidate only the Hermes overview key.
  • No console package is added to the workspace graph; types and helpers stay within the Bob app.

  2. Logged-in Bob user can open both /hermes-console and the stock dashboard.
  3. All stale console sections render from live Hermes data on desktop and narrow mobile widths.
  4. Connector and cron actions return visible success/failure and refresh state.
  5. No origin bearer or connector secret appears in browser JS, logs, repository, or Bob persistence.
  6. Focused tests, typecheck, build, full tests, CI, deploy, and live runtime checks are reported as distinct proof boundaries.
