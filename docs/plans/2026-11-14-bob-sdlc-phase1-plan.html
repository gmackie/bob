Goal: a read-only, live /sdlc page in Bob that draws the durable coordinator's item state machine. It has a Fleet → Project → Repo → Item drill-down and a plan dependency view, and it's fed from hetzner-bob through a Cloudflare Durable Object.

Architecture: the coordinator's worker gains an edge exporter that copies Flightdeck's checkpointed outbound-push pattern. It sends a full snapshot once, then the plan and item snapshots changed since its checkpoint, to POST /api/sdlc/ingest on the Bob Worker. A per-workspace SdlcEdge Durable Object stores the latest snapshots, keeps a short delta log, and streams to browsers over hibernatable websockets. A new pure package, @bob/sdlc-view, holds the presentation spec (generated from the contract's enums), the reducer and the aggregations, so mobile and the TUI can reuse them in later phases. Projects come from BizPulse's existing repos.list.

Tech stack: Node 24 ESM and node:test (coordinator); TypeScript and Vitest 4 (@bob/sdlc-view, apps/bob); Cloudflare Durable Objects with SQLite storage and the WebSocket Hibernation API; vinext and React 19 for the page; jj for version control.

Decisions this plan relies on

Transport

In Phase 1 the exporter POSTs batches, as Flightdeck does, rather than holding a websocket. Data flows one way until commands arrive in Phase 2, which adds a command channel.

Who can see it

The edge passes a verified Bob user id as the actor (decided). Phase 1 is read-only, so viewers are a user-id allow-list, SDLC_VIEWER_USER_IDS, following the existing HERMES_OPERATOR_USER_IDS pattern. Per-user actors arrive with commands.

Projects

BizPulse owns the mapping (decided). repos.list already returns startupId, startupName, provider and repoSlug. An item is joined when repository.integrationId = "forgegraph" and repositoryId equals the slug or its last segment. Anything else goes under “Unassigned”. No BizPulse change is needed.

Truth

The coordinator stays the only writer. The DO keeps only the newest snapshot per resource (by resourceVersion) and a watermark. When it notices a gap it asks for a fresh snapshot instead of guessing.

import { DatabaseSync } from 'node:sqlite';
import { readFileSync, realpathSync, existsSync } from 'node:fs';
import { resolve } from 'node:path';

const HEARTBEAT_MS = 30_000;

/** Pushes coordinator plan and item snapshots to Bob's SdlcEdge. Read-only:
 * it never changes domain state, and keeps its checkpoint in a separate database. */
export function edgeExporter({ coordinator, endpoint, token, checkpoint, fetch: send = fetch, timeoutMs = 5000, now = Date.now }) {
  const url = new URL(endpoint);
  if (url.protocol !== 'https:' || url.username || url.password || url.search || url.hash || url.pathname !== '/api/sdlc/ingest') throw new Error('Edge needs an HTTPS /api/sdlc/ingest endpoint');
  if (!/^[A-Za-z0-9_-]{32,256}$/.test(token ?? '') || !checkpoint || checkpoint === ':memory:') throw new Error('Invalid edge configuration');
  const source = coordinator.db.prepare('PRAGMA database_list').all().find(row => row.name === 'main')?.file;
  const destination = existsSync(checkpoint) ? realpathSync(checkpoint) : resolve(checkpoint);
  if (source && realpathSync(source) === destination) throw new Error('Edge checkpoint must be a separate database');
  const db = new DatabaseSync(checkpoint);
  db.exec('CREATE TABLE IF NOT EXISTS edge_checkpoint (owner TEXT PRIMARY KEY, position INTEGER NOT NULL, sent_at INTEGER NOT NULL)');
  const owner = JSON.stringify([coordinator.tenant, coordinator.owner, url.href]);
  const read = () => db.prepare('SELECT position, sent_at FROM edge_checkpoint WHERE owner=?').get(owner);
  const save = position => db.prepare('INSERT INTO edge_checkpoint VALUES (?,?,?) ON CONFLICT(owner) DO UPDATE SET position=excluded.position, sent_at=excluded.sent_at').run(owner, position, now());
  const reset = () => db.prepare('DELETE FROM edge_checkpoint WHERE owner=?').run(owner);
  const q = (name, body) => coordinator.call(name, { contractVersion: '1', ...body });

  function snapshot() {
    // Read the watermark first: anything written during the scan is re-sent as a change.
    const watermark = coordinator.watermark(), plans = [], items = [];
    let afterPlanId = null;
    do {
      const page = q('ListPlans', { limit: 50, ...(afterPlanId ? { afterPlanId } : {}) });
      for (const entry of page.plans) {
        const plan = q('GetPlan', { resourceId: entry.planId });
        plans.push(plan);
        for (const summary of plan.items) items.push(q('GetItem', { resourceId: summary.itemId }).item);
      }
      afterPlanId = page.nextPlanId;
    } while (afterPlanId);
    return { kind: 'snapshot', watermark, plans, items };
  }

  function changes(position) {
    const page = q('ReadEvents', { cursor: coordinator.cursor(position), limit: 100 });
    if (!page.events.length) return null;
    const plans = [], items = [];
    for (const id of new Set(page.events.map(event => event.resourceId))) {
      try { items.push(q('GetItem', { resourceId: id }).item); }
      catch (error) { if (error.code !== 'NotFound') throw error; plans.push(q('GetPlan', { resourceId: id })); }
    }
    return { kind: 'changes', fromSequence: position, watermark: page.events.at(-1).sequence, plans, items };
  }

  async function post(batch) {
    const response = await send(url.href, { method: 'POST', redirect: 'error', signal: AbortSignal.timeout(timeoutMs),
      headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
      body: JSON.stringify({ contractVersion: '1', ...batch }) });
    if (!response.ok) { await response.body?.cancel(); throw new Error('Edge unavailable'); }
    const result = await response.json();
    if (result.resync === true) { reset(); throw new Error('Edge requested a fresh snapshot'); }
    if (result.accepted !== true || result.watermark !== batch.watermark) throw new Error('Edge did not accept the batch');
  }

  return {
    async flush() {
      const state = read();
      let batch = null;
      if (!state) batch = snapshot();
      else {
        try { batch = changes(state.position); }
        catch (error) { if (error.code !== 'CursorExpired') throw error; batch = snapshot(); }
        if (!batch) {
          if (now() - state.sent_at < HEARTBEAT_MS) return { kind: 'idle', sent: 0 };
          batch = { kind: 'heartbeat', watermark: state.position, plans: [], items: [] };
        }
      }
      await post(batch);
      save(batch.watermark);
      return { kind: batch.kind, sent: batch.plans.length + batch.items.length };
    },
    close() { db.close(); },
  };
}

export function loadEdgeConfig(path, env = process.env) {
  const config = JSON.parse(readFileSync(path, 'utf8'));
  if (typeof config.tokenEnv !== 'string' || !/^[A-Z][A-Z0-9_]*$/.test(config.tokenEnv)) throw new Error('Edge tokenEnv is required');
  return { endpoint: config.endpoint, checkpoint: config.checkpoint, token: env[config.tokenEnv] };
}

const exporterState = () => ({ failures: 0, retryAt: 0 });
async function flushExporter(step, exporter, state, log) {
  if (!exporter || Date.now() < state.retryAt) return;
  try {
    const result = await exporter.flush();
    state.failures = 0; state.retryAt = 0;
    const count = result.exported ?? result.sent ?? 0;
    if (count) log({ at: new Date().toISOString(), step, outcome: 'exported', count });
  } catch {
    state.retryAt = Date.now() + Math.min(1000 * 2 ** Math.min(state.failures++, 6), 60000);
    log({ at: new Date().toISOString(), step, outcome: 'unavailable' });
  }
}

export function reduce(view: EdgeView, message: EdgeMessage): EdgeView {
  if (message.type === "status") return { ...view, coordinatorSeenAt: message.coordinatorSeenAt };
  const base = message.type === "snapshot" ? { ...emptyView(), topology: message.topology } : view;
  const plans = { ...base.plans }, items = { ...base.items };
  for (const p of message.plans) if (newer(plans[p.planId], p)) plans[p.planId] = p;
  for (const i of message.items) if (newer(items[i.itemId], i)) items[i.itemId] = i;
  return { ...base, seq: message.seq, plans, items, coordinatorSeenAt: message.coordinatorSeenAt };
}

export function planLayers(plan: PlanSnapshot): string[][] {
  const ids = plan.definition.items.map((i) => i.itemId);
  const depth = new Map(ids.map((id) => [id, 0]));
  for (let pass = 0, changed = true; changed && pass < ids.length; pass++) {
    changed = false;
    for (const d of plan.definition.dependencies) {
      const next = (depth.get(d.upstreamItemId) ?? 0) + 1;
      if (next > (depth.get(d.downstreamItemId) ?? 0)) { depth.set(d.downstreamItemId, next); changed = true; }
    }
  }
  const layers: string[][] = [];
  for (const id of ids) (layers[depth.get(id) ?? 0] ??= []).push(id);
  return layers;
}

import { emptyView, reduce, type EdgeMessage, type EdgeView, type ItemSnapshot, type PlanSnapshot } from "@bob/sdlc-view";

export interface IngestBatch { contractVersion: "1"; kind: "snapshot" | "changes" | "heartbeat"; watermark: number; fromSequence?: number; plans: PlanSnapshot[]; items: ItemSnapshot[] }
export interface EdgeState { watermark: number; view: EdgeView; topologyAt?: number }
export type IngestResult = { accepted: true; watermark: number } | { accepted: false; resync: true };
type Delta = Extract<EdgeMessage, { type: "delta" }>;

export const emptyEdge = (): EdgeState => ({ watermark: 0, view: emptyView() });

export function parseBatch(value: unknown): IngestBatch | null {
  const b = value as Partial<IngestBatch> | null;
  if (!b || b.contractVersion !== "1" || !["snapshot", "changes", "heartbeat"].includes(b.kind as string)) return null;
  if (!Number.isSafeInteger(b.watermark) || (b.watermark as number) < 0 || !Array.isArray(b.plans) || !Array.isArray(b.items)) return null;
  if (b.fromSequence !== undefined && (!Number.isSafeInteger(b.fromSequence) || b.fromSequence < 0)) return null;
  return b as IngestBatch;
}

export function applyBatch(state: EdgeState, batch: IngestBatch, now: number): { state: EdgeState; result: IngestResult; message: EdgeMessage | null } {
  const behind = batch.kind === "changes" ? (batch.fromSequence ?? 0) > state.watermark
    : batch.kind === "heartbeat" ? batch.watermark > state.watermark : false;
  if (behind) return { state, result: { accepted: false, resync: true }, message: null };
  const accepted: IngestResult = { accepted: true, watermark: batch.watermark };
  if (batch.kind === "heartbeat") {
    const message: EdgeMessage = { type: "status", coordinatorSeenAt: now };
    return { state: { ...state, view: reduce(state.view, message) }, result: accepted, message };
  }
  const seq = state.view.seq + 1;
  const message: EdgeMessage = batch.kind === "snapshot"
    ? { type: "snapshot", seq, plans: batch.plans, items: batch.items, topology: state.view.topology, coordinatorSeenAt: now }
    : { type: "delta", seq, plans: batch.plans, items: batch.items, coordinatorSeenAt: now };
  const watermark = batch.kind === "snapshot" ? batch.watermark : Math.max(state.watermark, batch.watermark);
  return { state: { ...state, watermark, view: reduce(state.view, message) }, result: accepted, message };
}

/** In-memory only: after the DO hibernates or restarts, clients simply get a snapshot. */
export class DeltaLog {
  private entries: Delta[] = [];
  constructor(private readonly limit = 200) {}
  push(message: EdgeMessage) {
    if (message.type === "snapshot") this.entries = [];
    else if (message.type === "delta") { this.entries.push(message); if (this.entries.length > this.limit) this.entries.shift(); }
  }
  since(cursor: number, current: number): Delta[] | null {
    if (cursor === current) return [];
    const first = this.entries[0];
    if (!first || cursor < first.seq - 1 || cursor > current) return null;
    return this.entries.filter((d) => d.seq > cursor);
  }
}

export function snapshotOf(state: EdgeState): EdgeMessage {
  const { view } = state;
  return { type: "snapshot", seq: view.seq, plans: Object.values(view.plans), items: Object.values(view.items), topology: view.topology, coordinatorSeenAt: view.coordinatorSeenAt };
}

export function helloReply(state: EdgeState, log: DeltaLog, cursor: number | null): EdgeMessage[] {
  const deltas = cursor === null ? null : log.since(cursor, state.view.seq);
  return deltas ?? [snapshotOf(state)];
}

import type { TopologyRepo } from "@bob/sdlc-view";
import { applyBatch, DeltaLog, emptyEdge, helloReply, type EdgeState, type IngestBatch, type IngestResult } from "./store";

export interface EdgeStorage { get(): Promise<EdgeState | undefined>; put(state: EdgeState): Promise<void> }
export interface EdgeSocket { send(data: string): void }
const TOPOLOGY_TTL_MS = 5 * 60_000;

export class EdgeController {
  private state: EdgeState | null = null;
  private readonly log = new DeltaLog();
  constructor(
    private readonly storage: EdgeStorage,
    private readonly sockets: () => EdgeSocket[],
    private readonly now: () => number = Date.now,
    private readonly loadTopology?: () => Promise<TopologyRepo[]>,
  ) {}

  private async current(): Promise<EdgeState> {
    this.state ??= (await this.storage.get()) ?? emptyEdge();
    return this.state;
  }

  async ingest(batch: IngestBatch): Promise<IngestResult> {
    const { state, result, message } = applyBatch(await this.current(), batch, this.now());
    if (!result.accepted) return result;
    this.state = state;
    await this.storage.put(state);
    if (message) { this.log.push(message); this.broadcast(JSON.stringify(message)); }
    return result;
  }

  async hello(socket: EdgeSocket, cursor: number | null): Promise<void> {
    const fresh = await this.refreshTopology();
    for (const message of helloReply(await this.current(), this.log, fresh ? null : cursor)) socket.send(JSON.stringify(message));
  }

  /** Returns true when the topology changed, so the client needs a full snapshot. */
  private async refreshTopology(): Promise<boolean> {
    const state = await this.current();
    if (!this.loadTopology || this.now() - (state.topologyAt ?? -Infinity) < TOPOLOGY_TTL_MS) return false;
    try {
      const topology = await this.loadTopology();
      this.state = { ...state, topologyAt: this.now(), view: { ...state.view, topology } };
      await this.storage.put(this.state);
      return true;
    } catch {
      return false; // keep the last good topology
    }
  }

  private broadcast(data: string) {
    for (const socket of this.sockets()) { try { socket.send(data); } catch { /* closed socket */ } }
  }
}

export function bearerMatches(header: string | null, token: string | undefined): boolean {
  if (!token || token.length < 32 || !header?.startsWith("Bearer ")) return false;
  const a = new TextEncoder().encode(header.slice(7)), b = new TextEncoder().encode(token);
  let diff = a.length ^ b.length;
  for (let i = 0; i < Math.max(a.length, b.length); i++) diff |= (a[i] ?? 0) ^ (b[i] ?? 0);
  return diff === 0;
}

const listed = (userId: string, csv: string | undefined) => (csv ?? "").split(",").map((s) => s.trim()).filter(Boolean).includes(userId);

export async function handleSdlcRoute(request: Request, env: SdlcRouteEnv, getUserId: () => Promise<string | null>): Promise<Response> {
  const { pathname } = new URL(request.url);
  if (!env.SDLC_EDGE_WORKSPACE_ID || !env.SDLC_EDGE) return Response.json({ error: "sdlc edge not configured" }, { status: 503 });
  const stub = env.SDLC_EDGE.get(env.SDLC_EDGE.idFromName(env.SDLC_EDGE_WORKSPACE_ID));
  if (pathname === "/api/sdlc/ingest") {
    if (request.method !== "POST" || !bearerMatches(request.headers.get("authorization"), env.SDLC_EDGE_INGEST_TOKEN)) {
      return Response.json({ error: "unauthorized" }, { status: 401 });
    }
    const body = await request.text();
    if (body.length > 4_000_000) return Response.json({ error: "batch too large" }, { status: 413 });
    return stub.fetch(new Request("https://sdlc-edge/ingest", { method: "POST", body, headers: { "content-type": "application/json" } }));
  }
  if (request.headers.get("upgrade")?.toLowerCase() !== "websocket") return new Response("expected websocket", { status: 426 });
  const userId = await getUserId();
  if (!userId) return Response.json({ error: "unauthorized" }, { status: 401 });
  if (!listed(userId, env.SDLC_VIEWER_USER_IDS)) return Response.json({ error: "forbidden" }, { status: 403 });
  return stub.fetch(new Request("https://sdlc-edge/ws", request));
}

    const { pathname } = new URL(request.url);
    if (pathname === "/ingest" && request.method === "POST") {
      const batch = parseBatch(await request.json().catch(() => null));
      if (!batch) return Response.json({ error: "invalid batch" }, { status: 400 });
      return Response.json(await this.controller.ingest(batch));

      this.ctx.acceptWebSocket(pair[1]);
      return new Response(null, { status: 101, webSocket: pair[0] });
    }
    return new Response("not found", { status: 404 });
  }

    if (typeof message !== "string" || message.length > 1024) return;
    let parsed: { type?: unknown; cursor?: unknown };
    try { parsed = JSON.parse(message); } catch { return; }
    if (parsed.type === "hello") await this.controller.hello(ws, typeof parsed.cursor === "number" ? parsed.cursor : null);

"use client";
import { useEffect, useReducer, useRef, useState } from "react";
import { emptyView, reduce, type EdgeMessage, type EdgeView } from "@bob/sdlc-view";

export type EdgeConnection = "connecting" | "live" | "reconnecting";

export function useSdlcEdge(): { view: EdgeView; connection: EdgeConnection } {
  const [view, dispatch] = useReducer(reduce, undefined, emptyView);
  const [connection, setConnection] = useState<EdgeConnection>("connecting");
  const seq = useRef<number | null>(null);

  useEffect(() => {
    let socket: WebSocket | null = null, attempt = 0, closed = false;
    let timer: ReturnType<typeof setTimeout> | undefined;
    const open = () => {
      const url = new URL("/api/sdlc/ws", window.location.href);
      url.protocol = url.protocol === "https:" ? "wss:" : "ws:";
      socket = new WebSocket(url);
      socket.onopen = () => { attempt = 0; setConnection("live"); socket?.send(JSON.stringify({ type: "hello", cursor: seq.current })); };
      socket.onmessage = (event) => {
        const message = JSON.parse(String(event.data)) as EdgeMessage;
        if (message.type !== "status") seq.current = message.seq;
        dispatch(message);
      };
      socket.onclose = () => {
        if (closed) return;
        setConnection("reconnecting");
        timer = setTimeout(open, Math.min(30_000, 1000 * 2 ** attempt++));
      };
    };
    open();
    return () => { closed = true; clearTimeout(timer); socket?.close(); };
  }, []);

  return { view, connection };
}

Rollback

  • Coordinator: remove --edge from the worker unit and restart. The exporter reads only and has its own checkpoint database, so the coordinator's state is untouched.
  • Worker: redeploy the previous version. Keep the DO class and its migration in place, because deleting a DO class needs its own migration; an unused class costs nothing.

Risks specific to Phase 1

RiskMitigation
The DO stores the whole view as one storage value. SQLite-backed DO values are limited to about 2 MB.Fine at today's plan sizes (≤ 100 items each). If needed, move to one key per plan and item; the controller interface doesn't change.
Production repositoryId values may not match BizPulse slugs.Unmatched repos appear under “Unassigned” showing their raw id, so a mismatch is visible, not silent. Fix the data in BizPulse.
STATE_EDGES may not match the real transitions.Task 4 step 2 checks them against execution.mjs. States can't be missing, because a test enforces full coverage.
Restoring the coordinator database from a backup can leave the exporter's checkpoint ahead of the restored data. Events written after the restore, up to the old checkpoint position, would then be skipped (review of Task 1).After any restore, delete edge.sqlite to force a snapshot; this is a runbook step. Later fix: store a database identity in the checkpoint.
Two coordinator owners pushing to one workspace's edge would overwrite each other's snapshots (review of Task 1).Phase 1 has a single actor. Key the DO by workspace and owner before adding a second actor.
vinext's Worker build may not expose a named DO export.Task 9 step 5 runs pnpm build and checks the export before anything ships.
