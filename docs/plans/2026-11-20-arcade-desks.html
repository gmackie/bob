Bob Arcade slice 2: HUD + Agent Desks In progress

2026-11-20 · gmackie/bob @ BOB-98-arcade-desks · BOB-98 (epic BOB-91, phase 1)

Plan: add a pure desks lens to @bob/arcade. It picks the up-to-6 items worth watching and turns their live tail and CI into desk cards. Then switch the phone and web edge clients from watching one item to watching a set. The edge already supports a set (BOB-94, live in production) and the shipped-today feed (BOB-95). This slice is client code only: no native dependency and no runtime-version bump, so it ships over the air.

Data flow

EdgeView→ chooseDesks(view, previous)→ watch {itemIds ≤ 6}→ SdlcEdge DO→ tail · ci · tailUnavailable→ desks(view, ids, detail)→ Desk cards

The edge only sends tail and CI detail to sockets that watch an item, so whichever desks are chosen get the live data. One socket serves both the item screen and the desks: the focused item always comes first in the set, and desks fill the remaining slots.

Which items get a desk

0Needs you (attention needs_human)
1Agent working: running, waiting-input
2Checking: validating, review, deploying
3Starting: reserved, execution-unknown

Ties keep the previous desk, then fall back to sorting by itemId. Kept desks hold their slot, and new ones fill the free slots. Desks only move when their item moves to a different rank or leaves the floor, and the watch message is re-sent only when the set of ids changes.

Scope

Goals

  • One chooseDesks and desks function, shared by web and native
  • Phone session: a watch set (focus + desks), opt in to shipped-today
  • Arcade on iPad: desk grid; on iPhone: desk strip; tap a desk to open its item
  • HUD TODAY count from shipped entries (local day)
  • Web /cockpit: a desks row and a TODAY counter

Non-goals

  • Edge or protocol changes (already shipped)
  • Answering a question from a desk (it opens the item screen)
  • XP, sound, or replay (phase 5)
  • Native builds and runtime-version bumps

Risks

Medium The edge caps tail fan-out per socket. Desks plus the item screen share the 6 slots. The focused item is always first, so the item screen never loses its live tail.

Low Watch churn while the floor is busy. Desks stay sticky, the watch is re-sent only when the ids change, and the edge replays tail and CI only for ids newly added to the set.
